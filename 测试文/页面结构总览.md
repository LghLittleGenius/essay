# OneNAC 页面结构总览

## 1. 一级页面

左侧一级菜单固定为 8 个，名称和顺序不可调整：

1. 概览
2. 节点
3. 准入策略
4. 网络设备
5. 边缘节点
6. RADIUS配置
7. 门户认证
8. 日志审计

`系统设置` 固定放在左下角，不计入一级页面。策略模拟固定放在 `准入策略` 页面内，不放右上角，也不新增一级菜单。

## 2. 能力归属

| 能力 | 页面位置 | 固定边界 |
| --- | --- | --- |
| Edge 首次接入、审批、接口和运行状态 | 边缘节点 | Edge 自动发现 Ping64，管理员只审批，不导入配置包、不填写服务器地址 |
| 交换机、WLC/AP、SNMP/WLC/API | 网络设备 | 设备是独立一级对象；Edge 详情只展示关联摘要 |
| NAS、802.1X、MAB、EAP、Accounting、CoA | RADIUS配置 | NAS 共享密钥只引用凭据，不显示明文 |
| 授权条件、VLAN、ACL、Reject、Portal 意图 | 准入策略 | 当前 P0 只发布 RADIUS Access-Request 决策 |
| 策略模拟 | 准入策略 -> 策略模拟 | Server 只读推演，不生成动作、不改变节点或会话 |
| Portal 页面、登记、访客、修复流程 | 门户认证 | Portal 运行在 Ping64 Server；不在 Portal Profile 保存 VLAN、ACL、CoA |
| 凭据、证书、IAM、安全门、日志保留 | 系统设置 | 只维护跨页面公共对象 |
| 全局认证、授权、执行、Edge、Portal 和管理日志 | 日志审计 | 业务详情保留局部日志，全局追溯统一在本页 |

## 3. 页面职责

| 页面 | 负责 | 不负责 |
| --- | --- | --- |
| 概览 | 展示准入闭环健康、告警和快捷跳转 | 不编辑协议参数 |
| 节点 | 展示节点、发现来源、认证会话、网络事实、策略结果和节点日志 | 不修改 Edge、RADIUS、Portal 定义 |
| 准入策略 | 编辑统一授权策略、运行策略模拟、执行发布校验 | 不保存密钥，不直接执行真实动作 |
| 网络设备 | 管理交换机、WLC/AP、SNMP/WLC/API、端口、SSID 和设备能力 | 不定义认证和授权规则 |
| 边缘节点 | 审批 Edge；配置接口、监听、DHCP Observe 和运行诊断 | 不维护网络设备主数据，不定义认证规则 |
| RADIUS配置 | 配置本地/外部认证、NAS、802.1X/MAB、EAP-TLS、Accounting、CoA | 不配置 SNMP，不编辑准入条件 |
| 门户认证 | 配置 Ping64 Portal Profile、Flow、访客和修复交互 | 不配置最终 VLAN、ACL、CoA 或 Disconnect |
| 日志审计 | 全局查询认证、授权、执行、节点、设备、Portal、访客和管理员日志 | 不直接修改业务对象 |
| 系统设置 | 管理凭据证书、Ping64 IAM 投影、真实执行安全门和日志保留 | 不保存现场对象 |

## 4. 固定接入顺序

1. 在客户网络的 DNS 中配置 `_onenac-edge._tcp.<search-domain>` SRV，指向 Ping64 HTTPS 服务。
2. Edge 服务接口通过客户网络取得 IP、默认网关、DNS 和 DNS Search Domain。
3. Edge 自动查询 SRV、校验 HTTPS 证书并进入 `边缘节点 -> 待接入`。
4. 管理员核对 Edge ID、序列号、服务 IP、MAC、TLS 指纹和最后在线时间后审批。
5. 在 Edge 详情配置服务接口、监听接口和 DHCP Observe。
6. 在网络设备新增交换机、WLC/AP 和 SNMP/WLC/API 采集，并绑定负责采集的 Edge。
7. 在 RADIUS配置新增 NAS，配置交换机的 RADIUS Client、802.1X/MAB、Accounting 和 CoA。
8. 按身份体系选择本地 EAP-TLS + Ping64 IAM 投影，或外部 RADIUS/NPS Proxy。
9. 在门户认证配置登记、访客或修复 Flow。
10. 在准入策略定义授权规则，先用策略模拟验证，再执行发布验证和发布。
11. 回到概览、节点和日志审计确认发现、认证、授权、执行和审计闭环。

## 5. 禁止项

1. 不提供 bootstrap/config.json 导出、导入或手工填写 Ping64 地址。
2. 不提供 DHCP Server、DHCP 地址池或 DHCP Enforcement；v1 只有 DHCP Observe。
3. 不把策略模拟作为执行动作、动作状态或动作确认结果。
4. 不把 TCP RST、SNMP Write、交换机 CLI/API、端口关闭或防火墙动作作为 P0 可发布策略。
5. 不把 802.1X 或策略模拟拆成一级菜单；网络设备和日志审计固定保留为一级页面。
